PREGUNTAS TEORICAS

1) Formas de conectar HTML con JavaScript

  • JavaScript interno: el código se escribe dentro de la etiqueta script en el mismo archivo HTML.

    <script>console.log("Hola desde JavaScript interno");</script>

  • JavaScript externo: el código se escribe en un archivo .js y se enlaza con el atributo src.

    <script src="script.js"></script>

2) Cómo ver resultados en la consola del navegador

  1. Escribir en el código JavaScript una instrucción como console.log("Hola mundo");
  2. Guardar los archivos index.html y script.js.
  3. Abrir index.html en el navegador.
  4. Abrir las herramientas de desarrollo con F12 o clic derecho y luego Inspeccionar.
  5. Seleccionar la pestaña Consola.
  6. Ver los mensajes mostrados con console.log().
  7. Si se modifica el código, guardar y recargar la página con F5.

3) Variables en JavaScript

Una variable es un espacio con nombre en la memoria donde se guarda un dato (número, texto, booleano, etc.) que se puede usar durante la ejecución del programa.

  • var: tiene alcance de función, permite reasignar y redeclarar.

    var edad = 20;

  • let: tiene alcance de bloque, permite reasignar pero no redeclarar.

    let nombre = "Ana"; nombre = "Luis";

  • const: tiene alcance de bloque y no permite reasignar.

    const PI = 3.1416;
